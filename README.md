Website de apresentação profissional de **Rafael Fernandes Durães**, estudante do 5º semestre de Ciência da Computação no **CEUB** (Brasília - DF). Desenvolvido com **arquitetura de CSS Modular** e **JavaScript Vanilla**.

---

## 🚀 Funcionalidades & Destaques

- **Arquitetura CSS Modular (5 Módulos):** Código limpo e organizado em `variables.css`, `base.css`, `components.css`, `sections.css` e `animations.css`.
- **Tema Claro / Escuro em Degradê:** Chaveador de tema dinâmico com persistência de preferência no `localStorage`.
- **Filtro Interativo de Projetos:** Filtragem dinâmica de trabalhos acadêmicos e extensões por categoria.
- **Modal de Detalhes de Projetos:** Visualização detalhada de tecnologias e trechos de código de cada projeto.
- **Design 100% Responsivo:** Layout adaptado para celulares, tablets e computadores.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5 Semântico, CSS3 Moderno (Glassmorphism & Flexbox/Grid), JavaScript ES6+.
- **Iconografia & Tipografia:** FontAwesome 6, Google Fonts (*Outfit* e *Fira Code*).
- **Versionamento:** Git & GitHub.

## 📁 Arquitetura do Projeto

```
Portifolio/
├── index.html              # Estrutura principal semântica
├── css/
│   ├── main.css            # Importador dos módulos CSS
│   ├── variables.css       # Tokens de design (Cores, Fontes, Sombras)
│   ├── base.css            # Reset e estilos globais
│   ├── components.css      # Botões, cards glassmorphism, badges
│   ├── sections.css        # Layouts do Hero, Sobre, Habilidades e Timeline
│   └── animations.css      # Efeitos de revelação e hover
├── js/
│   └── main.js             # Lógica do tema, modal, filtro e digitação
└── img/
    └── rafael.jpg          # Foto de perfil
```
